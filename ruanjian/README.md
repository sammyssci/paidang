# 羽球综合服务平台 - 使用说明

## 项目简介

这是一套完整的羽毛球综合服务网站，采用 **HTML5 + CSS3 + Tailwind CSS v3 + JavaScript + jQuery** 开发，使用 **localStorage** 模拟后端数据库。无需安装 Node.js、数据库或任何服务器，**直接用浏览器打开 HTML 文件即可运行**。

## 快速开始

### 1. 打开网站

在文件管理器中找到项目目录，双击打开 **`index.html`** 即可进入首页。

```
ruanjian/
├── index.html              ← 双击此文件开始
├── video-analysis.html     ← 视频AI分析
├── tactics.html            ← 战术洞察库
├── community.html          ← 羽毛球圈子
├── profile.html            ← 个人中心
├── css/common.css          ← 公共样式
├── js/
│   ├── mock-data.js        ← 模拟初始数据
│   ├── common.js           ← 公共逻辑（存储/认证/弹窗）
│   ├── index.js            ← 首页逻辑
│   ├── video-analysis.js   ← 视频分析逻辑
│   ├── tactics.js          ← 战术库逻辑
│   ├── profile.js          ← 个人中心逻辑
│   └── community.js        ← 圈子逻辑
└── README.md               ← 本说明文档
```

> **提示**：推荐使用 Chrome、Edge 或 Firefox 浏览器。首次打开会自动初始化模拟数据到 localStorage。

## 五大模块功能说明

### 🏠 首页（index.html）

- **顶部轮播**：赛事海报、教学课程、活动推荐，支持自动切换和手动切换
- **快捷入口**：一键跳转视频分析、战术库、圈子、个人中心
- **数据卡片**：热门赛事、球员战绩排行、热门教学视频榜单
- **资讯板块**：按分类筛选行业新闻、装备测评、新手入门文章
- **页脚**：网站介绍、使用帮助、意见反馈入口

### 🎬 视频AI分析（video-analysis.html）

1. **导入视频**
   - **本地上传**：选择你的羽毛球视频，**不限制文件大小**（mp4/webm/mov/avi/mkv 等）
   - 大视频自动存入浏览器 **IndexedDB**，刷新页面仍可播放
   - **在线链接**：粘贴 B 站教学链接或 mp4 直链

2. **模拟 AI 分析**
   - 自动识别：高远球、吊球、杀球、搓球、扑球、步伐
   - 可视化：动作分帧、击球热力图、步伐轨迹图
   - 文字报告：失误点、优缺点、训练建议

3. **操作功能**
   - 暂停/播放、裁剪片段
   - 保存分析报告（localStorage 持久化）
   - 分享到圈子、收藏视频

4. **历史记录**：查看/删除过往分析

### 📖 战术洞察库（tactics.html）

- **6 大分类**：单打、双打、混双、前场后场、防守反击、网前博弈
- **筛选**：按水平（新手/进阶/专业）、球员名、热门/最新排序
- **20+ 内置战术**：图文教程 + 配套视频
- **交互**：收藏战术、评论提问、一键跳转视频分析拆解对局

### 👤 个人中心（profile.html）

- **登录/注册**：弹窗式，localStorage 存储账号
- **个人信息**：修改头像、昵称、球龄、打法、段位、简介
- **我的资产**：收藏视频/战术、发布的帖子、分析视频、历史记录
- **数据统计**：AI 分析次数、发帖数、获赞数、观看时长
- **设置**：修改密码、清除缓存、退出登录、消息通知
- **我的动态**：点赞、评论、回复消息汇总

## 数据存储说明

- 所有数据存储在浏览器 **localStorage** 中，键名：`badminton_site_db`
- 刷新页面、关闭浏览器后数据**不会丢失**
- 「个人中心 → 设置 → 清除本地缓存」可重置为初始模拟数据
- 上传的视频以 Base64 存储，大文件可能占用较多空间

## 常见问题

**Q: 页面样式不正常？**  
A: 需要联网加载 CDN（Tailwind CSS、jQuery）。请检查网络连接。

**Q: 视频上传有大小限制吗？**  
A: **没有限制**。本地视频使用 IndexedDB 存储，支持几百 MB 甚至更大的文件（取决于浏览器与磁盘空间）。

**Q: 刷新后本地视频还能播放吗？**  
A: 可以。分析完成后视频已写入 IndexedDB，从历史记录打开即可重新播放。

**Q: 视频上传失败？**  
A: 请确认选择的是视频格式文件；极大文件保存时请稍等进度条完成。

**Q: 旧的 10MB 限制？**  
A: 已取消。请使用最新版 `video-storage.js`。

**Q: 登录后没反应？**  
A: 刷新页面即可。登录状态保存在 localStorage 中。

**Q: 如何重置所有数据？**  
A: 个人中心 → 设置 → 清除本地缓存；或在浏览器开发者工具中清除 localStorage。
